# Electronics Foundations

This is the first validated course bundle used by the prototype. The first round keeps the existing Ohm's-law lesson as the current learner entry point and adds a validated series-circuit lesson as the next step in a coherent sequence.

Planned introductory sequence:

1. Current in a single loop — voltage, current, resistance, and Ohm's law.
2. Resistance in series — one path, equivalent resistance, and shared current.
3. Voltage across parallel branches — branch voltage and equivalent resistance.
4. Electrical power — power as a rate of energy transfer.
5. Component behaviour — practical reasoning about simple components.

Only the first two lessons are currently implemented. The remaining sequence is intentionally documented before more activity types are added.

Run `pnpm validate:content` after changing the bundle. Validation checks the schema, references, visual brief, prose rules, and answer leakage.
