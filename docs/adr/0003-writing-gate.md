# ADR 0003: Enforce the prose contract in code

**Status:** Accepted

Learner-facing generated text passes a deterministic writing gate after generation. Hard rules cover negative parallelism, repeated forced triads, answer leakage, placeholders, banned openings, and excessive em dashes. Editing also receives a preservation check for values, units, equations, and citations.

Prompts still describe the preferred voice. The gate supplies repeatable acceptance criteria and tests.
