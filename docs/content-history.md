# Content history

Every pass that has changed the courses, in order, and what state that leaves each course in.
Written on 14 November 2026 from the git history and the release notes in
`docs/implementation-status.md`. The per-course record is `docs/content-ledger.json`, and
`docs/library.md` (generated by `node scripts/library-report.mjs`) shows each course's current
numbers beside it.

**Read this before planning any content work.** Every course has had its questions reworked
several times. A plan that says a course "needs a rewrite" has to name what is wrong with it now,
measured on the current bundle, and say which pass below failed to fix it.

## How the library was built

- **August 2026.** A prototype with Electronics Foundations and a Roman Empire placeholder course.
  The placeholder and its reference lesson were removed on 16 October.
- **Late September to 6 October 2026.** Eighteen courses written by agents from topic maps: Maths
  Foundations, Geometry, Linear Algebra, Calculus, Probability and Statistics, Logic, CS Basics,
  Physics, Chemistry, Biology, Astronomy, Engineering, Economics, Philosophy, Psychology, English,
  Python and SQL. Thirteen were rewritten into the v2 lesson format on 6 October. With
  Electronics and Rust these are "the twenty October courses" below.
- **15 October.** Rust Foundations (two lessons, then sixteen in 1.4.0).
- **3 November.** Forty-five courses written from researched curricula in `docs/curricula/`, one
  agent per course, in waves released as 1.4.0 to 1.9.0.
- **14 November.** How the Body Works and The Roman Republic, written from fetched source packs.

68 course directories: 67 listed and Drawing archived (1.9.2), because Delineare teaches drawing.

So the twenty October courses have had their lessons written from scratch three times
(6 October, 16 October and 1.3.0), and every course has been through about ten whole-library
passes since. Every course's questions have been reworked at least six times: the fix pass,
the choice reordering, the giveaway pass, the full read, the format judgement and the marking
pass, then either the full rewrite or the targeted pass.

## Why it kept happening

Each pass answered a real finding: a holistic review on 10 November (questions fitted the marker
more than the subject; right options were the longest in 45% of questions), learner-agent runs,
and George's own reading. What went wrong was the bookkeeping:

- No record said which passes each course had had, so each new session worked it out from
  whatever it read.
- Hand-off notes, briefs and reviews stayed in `docs/` after their work was done, several of them
  listing rewrites as "what is left".
- The 18 October courses kept their first-draft generator files (`content/<course>/authoring/`,
  `.authoring/candidate.json`, `scripts/prepare-<course>.ts`), so old wording was still in the
  repository and running a prepare script could have rebuilt a course from its October draft.

On 14 November the finished plans and briefs were deleted (they stay in git history), the
first-draft generators were removed, and the ledger and library report were added.

## Where each course stands

- **36 courses had the full question rewrite** (35 listed, plus Drawing). Their questions put
  material in front of the learner, use order and sort, quote sources where the subject has them,
  and have misconception distractors with feedback.
- **30 courses had the targeted pass.** Their teaching and numeric questions were judged sound;
  multiple choice no longer gives the answer away by length, every wrong option has feedback and
  every question has two hints. They have no order or sort questions (except the three writing
  courses), and many prompts are bare: maths, physics and chemistry by nature, Biology, Python,
  TypeScript and Systems Programming less defensibly.
- **2 new courses** were written to the current standard from fetched sources.

`docs/library.md` has the numbers per course. `docs/platform-overview.md` gives the assessment
and the open choices.

## Recording a pass from now on

1. Change the bundles.
2. Add the pass to `passes` in `docs/content-ledger.json`, and update `questions` (or add a
   `lessons` entry) for every course it touched.
3. Run `node scripts/library-report.mjs` and commit `docs/library.md` with the change.
   `node scripts/library-report.mjs --check` fails when the report is stale or a course is missing
   from the ledger.
4. Add a paragraph to `docs/implementation-status.md` for the release.
5. Delete the brief and any hand-off note once the pass has shipped.
